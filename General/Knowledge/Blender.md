[[Unicode Key Shortcuts]] `🖱️` = MMB hold
### Useful
- [[#Camera Movement]]
- [[#Selection]]
- [[#Edit Mode]]
- [[#Object Mode]]
- `⇧R` repeat last action
### Camera Movement
- `⇳` zoom in/out
- `^🖱️` zoom in/out

- `🖱️🖰` look around origin
- `⌥🖱️` set origin
- `⇧🖱️🖰` pan

- `⌥🖱️🖰` switch orthographic view, based on where you drag the mouse
- `⇧~` fly
    - `WASD` move
    - `QE` down/up
    - `⇧` faster
- `⇧B` focus to region
- `~` switch view
### Selection
- `LMB` select
- `A` select all
- `⌥A` deselect all
- `B` marquee box select
- `C` circle select
- `^RMB` lasso select
- `^i` invert selection
- `⇧L` select linked
- `⇧G` select similar
- `⌥LMB` select specific object
- `⌥Z` xray mode `select backfaces easily`
### Edit Mode
edits selected vertex/line/face
- `⇥` object mode toggle
- `⇧` precise movement
- `^` incremental movement
- `⇧D` duplicate
- `⌥D` duplicate linked
- `H` hide
- `⌥H` unhide all
- `⇧H` hide all except selected
- `D🖰` annotate
- `D 🖰R` erase annotation
- `Q` quick favs menu
##### Modeling (Edit Mode)
- `E` extrude
- `I` inset
- `^B` bevel

    - `⇳` add segments
- `^R` loop cut
    - `⇳` add cuts
- `G` move
- `GG` move along edge
- `S` scale
- `R` rotate
- `RR` trackball rotate
- `R` + `X/Y/Z` rotate axis
- `X` delete
- `K` knife
- `F` fill face
- `^⇧⌥S` shear
- `⇧W` bend
- `Y` split
- `V` rip
- `⌥V` rip fill
- `M` merge
- `⇧N` recalculate normals
- `^⇧N` flip normals
- `O` proportional editing toggle
- `⇧O` proportional falloff type
- `P` separate selection to new object
##### Selection (Edit Mode)
- `^L` select connected mesh
- `L` select connected mesh under cursor
- `⌥LMB` select edge/face loop
- `^⌥RMB` select edge ring
- `1/2/3` vertex/edge/face select mode
- `^⇧M` mirror current selection
- `^ +/-` select more/less
- `⇧E` select crease
##### Curve (Edit Mode)

`TL;DR Kelvin -> Joules`
Since [[temperature]] is just average translational [[kinetic energy]]
but [[temperature]] units like kelvin are not scientific and not based on joules, 
so we need conversion factor from temperature unit `kelvin` to energy unit `joule`
##### $k_B=\dfrac{PV}{TN}=1.380649\times10^{-23}~kg~m^2~s^{-2}~K^{-1}\implies E\sim k_BT$
`note: this value is exact since 2019 (kelvin is defined by this)`
- $J=kg~m^2~s^{-2}$ so $k_B$ is measured in `joules per kelvin` 
- $P$ pressure `Pa`
- $V$ volume `m^3`
- $T$ [[temperature]] `kelvin`
- $N$ molecule count `exact (not in moles)`
> [!tip]  for room temperature `300K` $E\sim k_BT\approx 4.1\times 10^{-21}J$
